# Skracacz URL

Projekt realizowany w ramach przedmiotu **Metody Wirtualizacji**.

## Opis

Aplikacja do skracania adresów URL oraz zliczania kliknięć w utworzone linki.

## Architektura

Projekt będzie składał się z trzech kontenerów:
- frontend,
- backend,
- baza danych.

Frontend będzie komunikował się wyłącznie z backendem za pomocą HTTP i JSON. Backend będzie komunikował się z bazą danych.

Do uruchamiania kontenerów wykorzystane zostaną Docker i Docker Compose.

## Wykorzystanie AI

Podczas realizacji projektu korzystamy z narzędzi AI jako wsparcia przy planowaniu projektu, tworzeniu dokumentacji oraz wyjaśnianiu zagadnień technicznych.
